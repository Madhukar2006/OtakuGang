## 📖 About

**OtakuGang** is a community-focused Minecraft SMP website built for players, anime fans, gamers, developers, and students.

The website combines a **Minecraft-inspired visual style** with an anime and gaming aesthetic. It provides a central place for server information, SMP details, community hubs, rules, staff, members, screenshots, and Discord access.

The project is designed to be lightweight, responsive, and easy to maintain.

---

- 🎮 Minecraft SMP information
- 🌌 Dark gaming-inspired interface

## 🗂️ Website Sections

### Server Hubs

The website presents the main OtakuGang community areas:

- 📋 Server Information
- 💬 Community
- 🎮 Gaming Hub
- 🌸 Anime Club
- 💻 Development Hub
- 📚 Study Zone

### Minecraft SMP

Includes information for both Minecraft editions:

**Java Edition**
```text
m1.matrixhosting.in:25573
```

**Bedrock Edition**
```text
Address: m1.matrixhosting.in
Port: 25658
```

The website also provides quick-copy functionality for server details.

### Community Gallery

A dedicated gallery section showcases Minecraft builds, worlds, exploration, and community moments.

Members can contribute screenshots through the community.

### Server Rules

The website includes the main community guidelines covering:

- No hacking or cheating
- No griefing
- Respect for members
- No spam
- Respect for player ownership
- Staff decisions
- Server-specific restrictions
- Using the correct channels

### Staff & Members

The website includes dedicated sections for:

- Founder & Owner
- Co-Founder & Admin
- Management
- SMP members

Minecraft player skins are displayed using Minecraft skin services.

## 🎨 Design

OtakuGang uses a dark visual system built around:

- Purple and violet accents
- Minecraft-inspired elements
- Anime-inspired details
- Pixel-style typography
- Neon highlights
- Responsive cards and grids
- Animated particles

The visual design combines a **Minecraft SMP atmosphere** with a modern gaming community interface.

## ⚙️ Core Interactions

The website includes several lightweight JavaScript interactions:

- Server IP copy buttons
- Toast notifications
- Mobile navigation menu
- Scroll-based navbar styling
- Intersection Observer animations
- Animated statistics
- Canvas-based background particles

No frontend framework is required.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Madhukar2006/OtakuGang.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd OtakuGang
```

### 3. Run the website

Since the project uses standard HTML, CSS, and JavaScript, it can be opened directly in a browser.

You can also use **VS Code Live Server** for local development.
